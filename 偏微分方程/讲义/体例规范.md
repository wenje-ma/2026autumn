# 《偏微分方程导论》笔记体例规范（所有子代理必须严格遵守）

## 一、文件结构

每个 markdown 文件对应教材的一个最小自包含小节，结构如下：

```
# 第X章 章名

## X.Y[.Z] 节名

（正文）
```

- 第一行为章标题（`# 第X章 章名`），第二行空行，第三行为节标题（`## X.Y 节名` 或 `## X.Y.Z 子节名`）。
- 节标题后空一行进入正文。
- 文件名采用 ED4DSE 式：`Ch0X-YY[-ZZ].md`，如 `Ch02-05-03.md`。未被再细分的节用 `Ch0X-YY.md`。

## 二、正文元素格式（严格仿照微分几何讲义）

### 定义
```
**定义 1.1**（名称）：设 ...，则称 ... 为 **名称**。
```

### 命题
```
**命题 1.2**（名称）：若 ...，则 ...。
```

### 定理
```
**定理 1.3**（名称）：
（1）...
（2）...
```

### 例
```
**例 1.4**（名称）：
（1）...
（2）...
```

### 注
```
**注**：...
```
或用引用块补充背景：
```
> $C^k(\Omega)$ 表示 ...
```

### 推导
```
*推导 1.A*（名称）：把 ... 细分，由 ... 得
$$
...
$$
求和取极限即得。$\blacksquare$
```

### 证明
```
*证明 1.B*（定理 1.3）：
（$\Rightarrow$）若 ...，则 ...
（$\Leftarrow$）反之，...
$\blacksquare$
```

### 核心结果
用 `\boxed{}` 框出：
```
$$
\boxed{u(x)=\int_{\partial\Omega} P(x,y)\,f(y)\,\mathrm dS_y}
$$
```

## 三、编号规则

- 每个文件内部，定义/命题/定理/例统一按 `1.1, 1.2, 1.3, ...` 编号（第一个数字恒为 1，因为每个文件只含一个最小节；若文件内自然分为两个部分，可用 `2.1, 2.2`）。
- 推导/证明按 `1.A, 1.B, 1.C, ...` 编号，与正文条目对应。
- 跨文件引用时写「见第 X.Y 节」即可，不写文件编号。

## 四、LaTeX 数学规范

- 所有数学公式用 `$...$`（行内）或 `$$...$$`（独立）。
- 微分算子：`\Delta`（Laplace）、`\nabla`（梯度）、`\partial_t`、`\partial_i`。
- 函数空间：`C^k(\Omega)`、`C^2(\Omega)\cap C(\bar\Omega)`、`L^2(\Omega)`、`H_0^1(\Omega)`。
- 积分测度：`\mathrm dx`、`\mathrm dS`、`\mathrm dt`。
- 向量用 `\boldsymbol{x}` 或粗体；区域用 `\Omega\subset\mathbb R^n`，边界 `\partial\Omega`，外法向 `\nu`。
- 常用记号：`B_R(x_0)` 球、`\omega_n` 单位球面面积、`\alpha(n)` 单位球体积。

## 五、内容要求

1. **忠实于教材**：不遗漏该小节的主要定义、定理、命题、例及其证明/推导思路。
2. **公式还原**：OCR 文本中公式常缺符号，须结合上下文与标准偏微分方程理论忠实还原（如 Laplace 基本解 $\Gamma(x-y)$、热核 $K(x,t)$、d'Alembert 公式、Poisson 核等）。
3. **物理/几何意义**：每节末尾配一句中文解释，说明该节核心结果的物理或几何意义。
4. **证明完整**：关键定理的证明须写出主要步骤，不能只写「显然」「易证」；结尾必须有 $\blacksquare$。
5. **不编造**：教材未提及的内容不主动添加；若教材证明从略，注明「证明从略」并给出思路概要。
