## 2. 全课程的“新视角”：为什么前七周要摒弃距离

老师的前七周（拓扑空间→连通→紧致）**从头到尾不引入度量、不引入 ε–δ**。这不是偷懒，而是一次观念上的“升维”。理解这一点，是读懂整门课的钥匙：

- **开集成为唯一的原初概念。** 在度量空间里我们习惯用“距离”说话（ε 球、收敛、连续）。Willard 在 §3 开篇就说：连续函数可以只用“开集的原像”来定义，完全不需要距离。于是我们把“什么样的子集叫开集”抽象为三条公理（G1–G3），由此开集、闭集、闭包、邻域、连续、同胚、连通、紧致……全部都可以只用开集描述。
- **邻域取代“到 x 的距离”。** 度量里“靠近 x”是由一串同心 ε 球（线性有序、且对称）刻画的；在一般拓扑里，“靠近 x”变为“属于 x 的邻域”。它**失去了线性序，也失去了对称性**（§4 的讨论）：y 可以属于 x 的每个邻域，而 x 不属于 y 的任何邻域。这是距离所没有的自由度。
- **开集越多，点与点越“不同”**（老师课堂语感）：离散拓扑把每个点都当成孤立的、彼此不同；平凡拓扑把所有点都糊在一起。拓扑的“粗细”是一种区分能力，类似概率论里 σ-代数的粗细。
- **新视角的回报**：连通、紧致这些性质一旦用开集定义，就不再依附于“欧氏空间”这个具体模型，可以搬到任意空间（函数空间、序空间、商的怪例……）上去，成为真正的**拓扑性质**（同胚保持的性质）。

直到 **w8–9**，为了谈“完备性”和 Baire 纲定理，我们才**重新请回度量**。原因：完备性（柯西列收敛）本质上是度量结构的概念，不是拓扑概念——拓扑只能区分“能否用网收敛”，分辨不出“差一点点没收敛”的柯西列。

## 3. 主线：一条链把这些主题串起来

```
开集公理(G1–G3)
   └─► 闭集 / 闭包 / 内部 / 边界 / 邻域 / 基 / 子基     (w1–2)
        └─► 连续函数(开集原像是开集) ⟺ 同胚 / 嵌入 / 开闭映射   (w3)
             ├─► 构造新空间：子空间 / 积空间(弱拓扑) / 商空间   (w3)
             ├─► 连通性(用开闭分离刻画) → 道路连通 → 局部连通    (w4–5)
             └─► 紧致性(开覆盖的有限子覆盖) → FIP → Tychonoff → 紧+豪斯多夫   (w6–7)
                    └─► 完备度量空间(柯西列收敛) → 闭子空间 → 完备化 → Baire纲   (w8–9)
```

三个“核心判定原则”，考试反复用到：
1. **连续 ⟺ 开集的原像是开集**（局部连续性可用“值域的邻域原像含定义域邻域”）。
2. **连通 ⟺ 没有非平凡的开闭子集** ⟺ 只能由开闭分离拆成两半才叫断开。
3. **紧致 ⟺ 一族闭集若满足有限交性质(FIP)则交集非空**；在度量空间里紧致 ⟺ 序列紧致。

## 4. 建议的学习/复习顺序

1. **先读 `01-拓扑空间.md`**：把开集、闭包、内部、邻域、基、分离公理、Urysohn 引理吃透。这是地基。
2. **再读 `02-连续函数与新空间.md`**：连续/同胚/开闭映射、积空间、商空间。注意“开集原像是开集”这一条怎么反复用。
3. **`03-连通性`** 与 **`04-紧致性`** 相对独立，可任意顺序；但紧致章用到连通的地方少，连通章用到紧致的地方也少，可分开复习。
4. **`05-完备度量空间`** 需要前面全部概念（尤其“闭包=逼近”的观念），并首次用回度量。
5. 最后读 **`06-复习·真题与解题方法.md`**：按真题把各章串起来，重点掌握四种常考证明手法（有限交性质、ε/3 技巧、对角线技巧、Baire 纲）。
6. 每章末尾有 **自测清单**，能不看笔记复述/证明才算过。

## 5. 记号约定（沿用 Willard）

- 拓扑空间记为 $(X,\tau)$，$\tau$ 中的元素叫**开集**；$\emptyset, X \in \tau$。
- $\overline E$ 或 $\mathrm{Cl}(E)$：闭包；$E^\circ$ 或 $\mathrm{Int}(E)$：内部；$\mathrm{Fr}(E)$：边界（frontier）。
- $x$ 的邻域系记 $\mathcal U_x$；邻域基记 $\mathcal B_x$。
- $\tau_1 \subseteq \tau_2$：$\tau_1$ 比 $\tau_2$ **弱/粗/小**（开集少），$\tau_2$ 比 $\tau_1$ **强/细/大**。
- $f^{-1}(B)$：原像（**拉回**）。原像与并、交都交换；像与并只单向成立（见 `02`）。
- $\prod_{\alpha} X_\alpha$：积空间（默认 Tychonoff/积拓扑）；$\pi_\alpha$：第 $\alpha$ 个投影。
- $X/\!\sim$：识别空间（商空间）；$S^1, S^2, \mathbb T^2$：单位圆、单位球面、环面。
